# Politique d'usage des données avec les assistants IA

## Ce qui est interdit dans un prompt

- Numéros de carte bancaire, IBAN, numéro de sécurité sociale.
- Clés d'API, mots de passe, jetons d'accès.
- Données clients nominatives hors des outils prévus à cet effet.

La passerelle bloque automatiquement une partie de ces contenus ; ce n'est pas une raison pour en coller.

## Conservation

- Les conversations LibreChat sont conservées 90 jours.
- Les journaux de la passerelle conservent l'identité de l'appelant, le modèle et le coût, pas le contenu des prompts.
