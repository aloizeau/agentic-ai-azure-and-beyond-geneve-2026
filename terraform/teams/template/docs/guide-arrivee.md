# Guide d'arrivée

## Première semaine

- Le poste de travail est remis le premier jour par le support, avec un compte Entra ID déjà actif.
- L'accès aux outils de l'équipe (dépôts GitHub, Grafana, LibreChat) est demandé par le responsable d'équipe, pas par l'arrivant.
- Un binôme est désigné pour les deux premières semaines.

## Accès à la plateforme d'agents

- LibreChat s'ouvre avec le compte Entra ID, sans mot de passe supplémentaire.
- Chaque appel à un modèle est attribué à la personne et à son équipe : le tableau de bord « Usage IA » le montre.
- Aucune clé d'API personnelle n'est distribuée : la passerelle s'occupe de l'accès aux modèles.
